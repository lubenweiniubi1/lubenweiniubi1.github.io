# 学习计划（雅思哥 App · 不充钱）

> 前提：目标 **7 分**，起点四六级水平，工作日约 1h、周末各 4-5h（每周约 14h），考试时间未定 → 按 **12 周** 排，考位定了再压缩或拉长。

## 先说三句实话

1. **四六级 → 7 分，12 周 × 14h 是偏紧的。** 7 分的瓶颈几乎一定在口语和写作（要求 sub-score 6.5-7），而这两项靠刷题库刷不出来，靠的是产出量 + 反馈迭代。如果 12 周后写作卡在 6，别慌，那是正常进度，加 4-6 周专项即可。
2. **App 的免费/付费边界会变。** 下面每个模块我都标了 `需核对`，请你打开雅思哥自己确认能不能白用；点不开的我给了替代方案。
3. **不充钱最大的缺口是"写作批改"。** 这个必须用 AI 顶上（对照官方评分标准让 AI 出反馈），否则写作会盲练。

### 三个缺口的处理

**1. 口语答案付费 —— 不是缺口，是好事。**
7 分口语的评分看的是流利度、词汇多样性、语法准确度，背来的答案在 Part3 追问下会直接崩。免费的题目本身就是你需要的全部：拿题 → 自己列 bullet point → 录音。答案付费这件事帮你省了一个坑。

**2. 写作看不到 description —— 这是真缺口，影响 Task1。**
- **Task2**：只要题干（那句 statement + 提问方式）就够了，雅思哥够用。
- **Task1**：核心是读图表数据，光有标题（"a bar chart about..."）没法练。
  → 替代：**剑桥真题 4-19 的 Task1 图表**（网上有 PDF），或 IELTS Cat 的写作板块。Task1 不需要"最新预测"，剑桥原题练手完全等效。

**3. 模考付费 —— 用 IELTS Cat 顶，但要注意一件事。**
IELTS Cat 是机考界面，节奏和真考接近，够用。但它和雅思哥的听力题库会重叠，**别把同一套题在两个平台各做一遍**——那属于无效重复。做法：雅思哥免费的听力用来**精听**，IELTS Cat 用来**限时套题**，两边分工，不混用。

## 四、分阶段细化

### 阶段一：基础积累（第 1-3 周）

目标：把词汇语法这块地基填上，**先不碰套题**。

- **词汇**：雅思核心词过完一轮。四步法，每天出声。
- **语法**：跟一轮语法课；每天用 AI 检查自己写的 3-5 个句子（时态、主谓、冠词、单复数）。
- **第 1 周内做一次摸底模考**（听力 + 阅读，IELTS Cat），只为定位，**不看分数焦虑**。
- 周末写作时间这三周先不写完整文章，改成**句子 → 段落**：主题句 + 论证 + 举例。
- 口语 10 min 照常，此阶段只求"能连续说 1 分钟不停"。

**验收**：高频词一轮过完；能写出一段 4-5 句、无低级语法错误的英文。

### 阶段二：方法学习（第 4-7 周）

目标：四科都建立"打法"，这是 7 分的分水岭。

- **听力**：吃透题型规则（填空、选择、匹配、地图），学关键词定位与同义替换。精听流程：听 → 对答案 → 逐句复听没听懂的 → 看文本 → 跟读。
- **阅读**：题型规则优先（判断题、Matching、Heading 是重点），练定位而非通读。
- **口语**：跟莱斯利的课学答题逻辑；**按当季题库整理自己的 bullet point**（每题 3-4 个自己的点，不背模板答案）。
- **写作**：跟 Lexi 的课学框架；**每个题型至少完成 1 篇完整写作**（Task2 的 agree/disagree、discussion、advantage、problem-solution、two-part，Task1 各图表各 1 篇）。每篇必须走：写 → 对照评分标准 → AI 反馈 → 重写。

**验收**：拿到任何一道题，能在 5 分钟内说出"这题该怎么做"。

### 阶段三：刷题复盘（第 8-12 周）

目标：把方法练成本能，**拒绝无效重复**。

- 周末各一套听力 + 一套阅读，限时，机考界面为佳。
- **错题体系**：每道错题记录 → 题型 / 错误原因（没听到、词不认识、定位错、时间不够、理解偏差）/ 下次怎么改。
- **每周一份刷题报告**：本周正确率、错因分布、下周要专项打的一项。
- 写作每周 1-2 篇，同一篇可以改两轮再换题。
- 口语进入**成套模拟**：Part1+2+3 连着说，计时，录音。
- 最后 2 周：至少 2 次完整模考（四科连着做，按真实时间）。

**验收**：错因分布明显收敛到 1-2 类；口语能连续完成一套不崩。

## 五、平台分工（避免无效重复）

两个平台题库会重叠，**同一套题不要在两边各做一遍**——那是典型的无效重复。分工固定下来：

| 用途 | 平台 |
|---|---|
| 单词听写 | 雅思哥 |
| 口语题目（当季） | 雅思哥 |
| Task2 题目 | 雅思哥 |
| 听力**精听**（逐句抠） | 雅思哥免费部分 |
| 听力/阅读**限时套题** | IELTS Cat |
| 完整模考（机考界面） | IELTS Cat |
| Task1 图表 | 剑桥真题 4-19 PDF |
| 方法课 | B 站（莱斯利 / Lexi） |
| 作文反馈 | AI + 官方评分标准 |

## 六、红线（照原则来）

- 不做"做题机器"——**做 1 套 + 复盘 1 小时 > 做 3 套不复盘**。
- 口语写作**不许上来就刷题库**，必须走完四阶段。
- 写作没有反馈就不算练过。不充钱 = 必须用 AI 补批改。
- 每天出声、动耳朵，词汇不能只用眼睛过。
