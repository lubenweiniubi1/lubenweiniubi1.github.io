## 零、设计原则（先读这段，否则后面看不懂为什么这么排）

### 1. 三条轨道，互不抢时间

| 轨道 | 强度 | 时间来源 | 全年是否中断 |
|---|---|---|---|
| **项目轨**（主） | 高 | 工作日晚 90min + 周六 3h | 不中断，每季一个主题 |
| **算法轨** | 恒定低 | 工作日晚开场 30min | **一天都不断** |
| **八股轨** | 寄生 | 周日 1h | 不中断，但只写本周碰到的 |
| **英语轨** | 碎片 | 通勤 + iTalki | 不中断 |

**为什么算法要"每天一点"而不是"某个季度集中刷"**：算法能力衰减极快，集中刷完 3 个月不碰就归零。而 Tesla 这类外企的算法轮不难（Medium 为主），靠的是**手不生 + 能边写边用英文讲**，不是靠峰值刷题量。

### 2. 八股必须从项目里长出来

**规则**：只整理你**这周真实碰到过**的问题。没做过的技术，不进八股文档。

原因：外企技术面是行为化追问（"你为什么这么选" → "代价是什么" → "换成 X 会怎样"）。背来的知识撑不过第二层追问，做过的能撑到第四层。

这也是"相辅相成"的具体含义 —— 项目产出八股，八股逼你把项目想透，两边互相加分。

### 3. 每季度末必须有一个"可被追问 40 分钟"的产出

不是"学完了"，是"有东西能给面试官看"。

| **M10** | W18–20 | 引入消息队列（NATS 或 Kafka 单节点）：登录事件异步落审计日志 + 异步发通知 | 幂等消费能通过"重复投递同一条消息"测试；有死信处理 |

## 七、关于 AWS / GCP 证书的结论

**结论：全年不安排考证。**

理由：
1. JD 里没有任何云厂商关键词，考察的是 K8s、分布式消息、设备通信 —— 都是"能力信号"而非"证书信号"
2. 证书在 SRE / DevOps / 解决方案架构师岗有分量，在 full-stack SWE 岗基本不被追问
3. AWS SAA 认真准备 60–100h ≈ 本计划里 Q3 M15（设备通信）+ 半个 M16 的时间。**M15 在这个 JD 下的价值远高于一张证书**

**替代方案已内置在计划里**：Q3 M16 是一次真实 AWS 部署。面试时说"我在 AWS 上部署过，ALB 健康检查和 target group 端口不匹配卡了一晚上"，比一张 SAA 可信得多。

**什么情况下推翻这个结论**：
- 你决定同时投 SRE / DevOps / 云厂商岗（分散风险）→ 在 W33–36 插入 SAA，砍掉 M17
- 公司报销且和晋升挂钩 → 那和面试无关，另算
- 你需要外部 deadline 才学得动云基础 → 承认这一点，然后照上一条办

**如果一定要考**：选 AWS SAA，时间放 Q3 末（W33–36），别选 GCP（外企在华环境 AWS 覆盖面更广），别在 Q1/Q2 考（那两个季度是打地基）。

## 八、算法方法论（比刷题量更重要，请认真执行）

外企算法轮评分里"沟通"占比常常 ≥ 30%。同样解出题，会讲和不会讲差一个档。

**每道题的固定流程（哪怕做 Easy 也走一遍）**：

```
1. 复述题目            → 确认自己没读错（英文面试里读错题极常见）
2. 问清约束            → 数据范围？有无重复？空输入？—— 主动问，别等提示
3. 举 1 个正例 1 个边界例
4. 说暴力解 + 复杂度   → 先给一个能跑的，别沉默思考超过 60 秒
5. 说优化方向          → "瓶颈在重复计算 / 在查找，所以我想用..."
6. 写码               → 边写边说自己在做什么
7. 自测               → 拿第 3 步的例子手动走一遍
8. 说复杂度 + 可能的进一步优化
```

**执行要求**：
- **每周至少 2 道全程出声用英文走完整流程**（这是本计划里最容易偷懒、也最不能偷懒的一条）
- 每月至少 1 次 iTalki 用来讲算法题，让外教打断你提问
- 超过 25 分钟没思路 → 直接看题解，理解后**当天不再写**，隔 3 天重写。硬磕 1 小时是最低效的学法
- 做错的题记进 `algo-mistakes.md`，只记"我当时的错误思路是什么"，不记题解

## 九、检查点与提前终止条件

**每季度末做一次诚实评估**，任一条触发就调整计划而不是硬推：

| 检查点 | 触发条件 | 动作 |
|---|---|---|
| W12 | 项目没上线 / 算法 < 50 题 | Q2 砍掉 M10（消息队列），先补完 Q1 |
| W24 | Go 写不出能跑的端点 | 放弃 Go 轨，Q3 全力做 K8s + 设备通信（Go 只是 a plus，不是门槛） |
| W24 | 未完成 2 次真实面试 | **立即投递**。没有真实面试反馈的准备是盲练 |
